# Localization / i18n

This project uses the native `Microsoft.AspNetCore.Mvc.Localization` framework.

## 1. Backend Services & Controllers
- Inject `IStringLocalizer<SharedResource> localizer`.
- Usage: `localizer["MyKey"]`

## 2. Razor Views
- At the top of the `.cshtml` file, inject the view localizer:
  ```html
  @using Microsoft.AspNetCore.Mvc.Localization
  @inject IViewLocalizer Localizer
  ```
- Usage: `@Localizer["WelcomeMessage"]`

## 3. Data Annotations (ViewModels)
- Use `ErrorMessageResourceName` and `ErrorMessageResourceType` for model validation attributes so errors are localized.
- Example: 
  ```csharp
  [Required(ErrorMessageResourceName = "RequiredError", ErrorMessageResourceType = typeof(SharedResource))]
  public string Name { get; set; }
  ```
